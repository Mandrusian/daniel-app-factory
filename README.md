# Daniel App Factory

**The feature requests have escaped containment.**

A playful, fully interactive parody of app development: unlimited ideas, one developer, and a suspiciously polished landing page.

**[Launch Daniel App Factory](https://mandrusian.github.io/daniel-app-factory/)**

## Features

- Create and manage your own imaginary software projects.
- Add feature requests, generate more ideas, and watch scope creep.
- Track pretend AI usage and developer patience.
- Simulate the build process, with all the optimism and none of the backend.
- Export project data and generate a real downloadable *coming soon* homepage.
- Works on desktop and mobile, in a single self-contained HTML file.

## Run locally

Download or clone the repository and open `index.html` in a browser. No dependencies, build step, or server needed.

Project changes are stored in your browser using `localStorage`; the GitHub Pages website does not provide online accounts or cloud synchronisation.

## About

Inspired by the fictional **Daniel App Factory** from *The Stallmanist Chronicles*. This is satire, not a functioning AI code generator. Generated homepages are deliberately placeholders.
